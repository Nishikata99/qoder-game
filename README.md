# Blood Ante · 血色底注

第一人称 3D 暗黑桌面博弈：21 点 × 血注王牌 × 三层处决。你坐在地下赌桌前，用牌面决定谁拿枪、由轮盘决定谁流血；连赢三层，赎回自己。

**技术栈**：React 19 · TypeScript ~7 · Three.js r187 · Tailwind CSS 4 · Vite 8 · Web Audio 实时合成
场景模型为自建 GLB，贴图由 Canvas 程序化生成，音效以 Web Audio 实时合成为主、少量采样。

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc -b + vite build → dist/
npm run preview    # 预览生产构建
npm test           # Vitest 单元测试（引擎规则）
npm run test:e2e   # Playwright 端到端（自动 build + preview）
npm run editor     # 本地数据编辑器，http://127.0.0.1:4798/
```

## 入口

单入口 `/`：走廊序章 →「点击画面 · 走进走廊」→ 左门「血色底注」开新局；右门「封」在有存档时读取进度继续。原「蔓延」子游戏已移除。

## 一局怎么打

1. **生命**：每层开局你有 4 格血（台面 3D 血袋），Boss 依次 4 / 4 / 5 格；开局双方各领 0 / 1 / 2 件补给。
2. **牌堆**：每回合重洗 11 张牌（点数 1–11 各一张，花色轮转）。没有 J/Q/K，也没有 A 的软硬切换，点数就是牌面相加。
3. **发牌**：双方各 1 明 1 暗。你的暗牌点数刻在牌背，自己知道；对手暗牌不可见。结算时亮底牌。
4. **目标 21**：血注王牌可以把本回合目标改成 24 或 27。每回合双方各摸 2 张王牌，跨回合最多留 1 张（因此回合开始最多 3 张）；要牌约 15% 概率再摸一张。王牌只能在自己的回合打，一回合可多次使用。
5. **你的回合**：要牌（H）或停牌（S）。爆牌后回合仍归你，只能打王牌抬高目标或停牌；摸到正好等于目标会自动停牌。
6. **结算**：更接近目标且不爆者获胜，赢家拿枪，枪口对准对手或自己。
   - 实弹：1 点伤害；锯子 +1。
   - 空膛打对手：枪权转移（手铐可锁住）。
   - 空膛打自己：结束本轮，没有补给。
   - 平局：不开枪，双方各摸一件道具。
   - 正好等于目标：赢家额外拿一件道具。
7. **道具**：只有持枪阶段才能使用（点击桌面道具）。每次使用都有演出，演出结束前无法操作。
8. **清层**：先播清层横幅，门前摆 2 件（首层）/ 3 件补给；约 3.2 秒后系统随机留下一件（无需点击），Boss 同样随机拿一件；随后进入下一层，第 2、3 层前播 2D 像素过场。

## 三层 Boss

| 层 | Boss | 它的生命 | 你的生命 | 开局补给 | 打空重装补给 | AI 性格 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 锈蚀看门人 | 4 | 4 | 0 件 | 1 件 | 谨慎：停牌线 15；你停牌且没到目标-3 时，跟到比你多一点 |
| 2 | 赌命收账人 | 4 | 4 | 1 件 | 2 件 | 赌徒：停牌线 17；落后时更贪，爱用手铐与放大镜 |
| 3 | 深渊执刑者 | 5 | 4 | 2 件 | 4 件 | 算牌：停牌线 19，按剩余牌堆估爆牌概率上下微调 1~3 |

## 八件道具

道具按层解锁，同时最多携带 8 件；单类还有各自上限（如镇定剂 4、借据 4、重锤 2、手套 2）。

| 道具 | 效果 | 解锁 |
| --- | --- | --- |
| 放大镜 | 看到当前膛内这一发，并标在弹盘上 | 第 1 层 |
| 镇定剂 | 立即恢复 1 点生命，不超过上限 | 第 1 层 |
| 锯子 | 下一发实弹伤害 +1；打出实弹后才失效 | 第 1 层 |
| 手铐 | 你下一次对它开空枪时，枪权不转移 | 第 2 层 |
| 护心镜 | 公开退掉当前这一发并从本局弹仓移除 | 第 2 层 |
| 借据 | 开枪阶段赌命：50% 自损 2 血，50% 恢复 1 血 | 第 2 层 |
| 重锤 | 翻转当前膛：实弹变空膛，空膛变实弹 | 第 3 层 |
| 窃贼手套 | 偷对手一件道具并立即使用；不能偷手套，偷到用不了会放回 | 第 3 层 |

## 十四张血注王牌

每回合双方从加权牌池各摸 2 张；王牌只在 21 点阶段使用，目标类王牌会重新结算双方手牌。

| 王牌 | 效果 |
| --- | --- |
| 血注·廿四 / 血注·廿七 | 本回合目标改为 24 / 27，双方重新获得行动权 |
| 封牌 | 把对手最后一张明牌弹回牌堆 |
| 割牌 | 把自己最后一张明牌弹回牌堆 |
| 易牌 | 交换双方最后一张明牌（暗牌不能交换） |
| 索牌·二 ~ 索牌·七 | 从牌堆抽出指定数字；已不在牌堆则无事发生 |
| 双喜 | 双方各抽一张王牌 |
| 销注 | 移除对手台面上的目标王牌，目标恢复 21 |
| 以爱资敌 | 强迫对手抽一张：优先最贴近目标且不爆的牌；没有安全牌就给最小的一张，哪怕爆牌 |

## 弹仓

- 容量开局 2 发，随层数与回合增长（每层 +2，每 2 回合 +1），上限 8。
- 2 发时固定 1 实 1 空；更多时 2–4 发实弹，且不超过一半（奇数可多 1 发）。
- 容量达到过 8 发后，之后每次重装容量在 2–8 之间随机。
- 打空才重装，不中途重洗；重装时双方按当前层各领 1 / 2 / 4 件补给。

## 表现与叙事

- 2D 像素层间过场（第 2、3 层）；胜利「赎契」8.5s、失败「补针」7.0s 两段 2D 结局。
- 胜利结局不可直接跳过（长按 Space / Esc 3 秒）；失败结局可直接跳过。
- 血量由 3D 血袋显示，点数由台面贴片显示；Boss 中弹有完整起身状态机，玩家中弹是 DOM 血斑 + 视野模糊。
- 手机端仅支持横屏触控（粗指针设备）；竖屏会出旋转门禁，桌面键鼠行为不变。
- 调试参数（仅开发模式）：`?seed=12345` 固定发牌与 AI 随机序列；`?skipcutscene=1` 跳过过场；`?cutscene=1` 强制播放；`?replaycutscene=1` 重播已看过的层间过场。

## 数据与本地编辑器

- `src/data/game.json`：关卡数值、王牌权重与图鉴、道具图鉴、音效路径。
- `src/data/narrative.json` / `beats.json` / `cutscenes.json`：叙事台词、分镜与结局。
- `npm run editor` 启动本地编辑器（4798）；保存会写回 JSON、备份到 `backups/editor/` 并自动重建 `dist`，另开 `npm run preview` 查看。
- 改数值或文案只动 JSON，不要改 `GameEngine.ts`；`dataSchema.test.ts` 会校验结构，编辑器也会在保存前校验。

## 架构

```text
src/data/                 数据化配置（关卡 / 王牌 / 道具 / 叙事 / 分镜）
src/game/GameEngine.ts    纯逻辑状态机（不依赖 React / Three / DOM）
src/scene/                3D 场景、运镜、程序化贴图、Boss 姿态
src/audio/                Web Audio 合成音效
src/components/           画布桥接、规则图鉴、王牌浮层、移动端触控
src/intro/                走廊序章
src/narrative/            旁白导演、2D 像素过场与结局
src/App.tsx               沉浸式 UI 覆盖层
```

跨层契约与协作规范见 **[AGENTS.md](./AGENTS.md)**；完整规则见 **[docs/游戏规则.md](./docs/游戏规则.md)**。

## 美术与音频

- 贴图由 Canvas 程序化生成；`public/assets/` 放同名 PNG 即可覆盖（`table`、`card-back`、`dust`、`mask-1~3`），删掉即回退。
- `public/models/` 为自建 GLB（赌桌、房间、霰弹枪、三层 Boss 半身像、道具等）；缺文件会回退程序化几何，不报错。
- 音效以 Web Audio 实时合成为主，`public/audio/` 存放少量采样（门、落牌、弹巢、补给托盘）。

## 部署

`vite.config.ts` 固定 `base: './'`，构建产物可直接部署到任意静态托管（含子路径），不会资源 404。线上站点由 Qoder Sites 发布；`.站点名称.qoder.site` 为工具生成的部署描述文件，不要手改。
