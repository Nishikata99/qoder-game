## 1. 三章分章逻辑与线索链

「那个人」名字：**小满**。玩家自愿走进来，找她。目的作为悬念贯穿，每章只揭一条线索，不解释世界观。

| 章 | 玩家在哪（现有场景名） | Boss | 压力怎么升级（全代码，setMood） | 查到「那个人」哪条线索 |
|---|---|---|---|---|
| 1 | 门厅·滴水的地下室 | 锈蚀看门人 | 基线：雾 0.042 / fov48 / 灯高 5.4 / vignette0.85 / 噪点 0.04 | 桌左角**纸片**：名字被撕去一半，只剩「满」字与撕边。Boss 半句：「上一个坐这位置的人，也攥着这么一张纸。」（入场 33s 处先说半句，局内第一次 roundStart 补后半句） |
| 2 | 账房·发霉的赌桌 | 赌命收账人 | 雾 0.05 / fov46 / 灯高 5.1 / vignette0.95 / 噪点 0.07 / 灯抖幅+30% | 过渡 T3 滑入**账页**：「小满。已收。」——确认全名与「已收」二字；毛巾绣字在本章变得可读（「满」） |
| 3 | 刑台·没有出口 | 深渊执刑者 | 雾 0.06 / fov44 / 灯高 4.8 / vignette1.05 / 噪点 0.10 / 灯抖幅+60%；门缝光熄灭 | 刑台悬挂轨道**刻痕名单**：末位「小满」，下一行是一道空白新刻痕——在等玩家。ch3 第一次 roundStart 时镜头扫过揭示 |

恐怖尺度（已拍板）：心理压抑为主。**不做血浆特写、不做突然出现的脸**；唯一「惊」是 Boss 突然转头（脚本化 head snap，整 run ≤2 次：ch2 一次、ch3 一次），其余靠灯、雾、声、空间变小。房间变小的感觉 = 灯逐章下降 + 雾逐章加浓 + fov 逐章收窄，不换房间几何。

## 2. 入场分镜（永久不可跳过，总长 ≈40s，含 T1）

挂载：坐下按钮点击 → `sound.unlock()` → 导演层接管（屏蔽键盘 H/S/F/R/空格、屏蔽道具点击）→ 分镜播完 → `game.start()`。
字幕：P5 式打字机逐字，带停顿；每段 ≤2 行；说完留白 1s 再淡出。键音用合成短 tick（不引外部素材）。
画面：上下黑边（letterbox DOM）+ 噪点/暗角加强；无跳过按钮、无「是否观看剧情」选项。

| 秒 | 机位/镜头 | 灯/后期 | 字幕（打字机） | 声音 |
|---|---|---|---|---|
| 0–2.5 | 全黑 | 灯 off；雾 0.06；vignette1.2；噪点 0.12 | （无） | 外部底噪 loop 淡入（主体），合成床兜底 |
| 2.5–5.5 | intro_wake：低机位、歪斜仰视吊灯 | 灯 off→flicker→steady | 「你醒了。」 | 钨丝电流声（合成）、灯丝 tick |
| 5.5–9 | 下摇到桌面**手印形污渍** | 灯 steady，光锥可见 | 「你不记得自己是怎么坐下的。」 | 椅吱（合成）、底噪持续 |
| 9–12.5 | 横移到桌左角**纸片**（半名「满」） | 同上 | 「你是自己走进来的。」 | 纸片轻响（合成噪声 hit） |
| 12.5–16 | 微转向身后**门缝光**面片，随即回正 | 门缝光一条冷白 | 「门在你身后锁了。」 | 铁链拖动 + 锁舌咔哒（合成，复用 reload 金属质感） |
| 16–20 | 落在玩家血袋架旁**毛巾**（绣字模糊不可读） | 灯微抖 | （无字幕，留白） | 只有底噪与滴水 |

## 3. 章节过渡 ×3（比入场短、节奏更快）

| 过渡 | 触发 | 时长 | 分镜 | 字幕 | 声音 |
|---|---|---|---|---|---|
| T1 入场→ch1 | 入场尾（36.6–40s） | ~3.4s | 已并入 §2 末行：Boss 抬头 + HUD 淡入 | 「它抬起头。」 | 低频 thump |
| T2 ch1→ch2 | `levelClear` 事件 | 6.5s | 0–2.6s 骑 SUPPLY_DELAY 窗口（画面本是 victory 远景）：黑边落下、灯压暗一档；2.6–6.5s 覆盖层压在 supply 面板**上方**（z-index 更高、pointer-events 阻断）：账房灯色渐入 + 收账人剪影抬头 | 「你找的人，欠我一笔。」（打字机快档，说完即收） | 算盘/硬币单响（合成 itemUse 变体）+ 底噪换层 |
| T3 ch2→ch3 | `levelClear` 事件 | 6.5s | 同 T2 结构；**账页面片**从右侧滑入停 2s：「小满。已收。」；随后刑台灯色渐入、门缝光熄灭 | 账页文字即字幕，不另加旁白 | 纸滑声 + 一声锁链 |

覆盖层时序核算：supplyOffer 在 t=2.6s 出现、12s 倒计时；覆盖层 t=6.5s 收起 → 玩家实际可选时间 ≥8.1s，引擎零改动（§6 ②）。
ch3 刻痕名单揭示不在过渡里：ch3 第一次 `roundStart` 时 setShot 扫过轨道 1.2s 再回 table。

restart 包装（§6 ③）：死亡屏「重新成为实验品」点击后播 ~4s 迷你入场——灯 flicker + 复用文案「灯没有熄灭，只是换了一位坐下的客人。」→ 直接 dealing。**同样不可跳过**，但不重播 40s 全入场。

## 6. 四个冲突点拍板记录（用户已授权「按你所想」）

1. **e2e vs 不可跳过**：e2e 等入场自然播完；入场+T1 ≤45s；统一 helper 等回合按钮（timeout 60s）；生产代码不留跳过口子、不留 dev 跳过 hook。
2. **过渡 vs supply 12s**：过渡 ≤6.5s，覆盖层 z-index 压住 supply 面板并阻断输入，收起后玩家仍有 ≥8.1s 选择；引擎零改动。
3. **restart vs 一命到底**：restart 包装为「换一位坐下的客人」4s 迷你入场（复用 App.tsx:628 文案），不可跳过；不重播全入场。
4. **规则卡 vs 入场**：保持现状（首访弹规则卡→关→坐下→入场）；规则卡可跳、入场不可跳，二者不冲突；窄屏 e2e 不受影响。

## 8. 音频：外部底噪接入与素材候选

**接入位置**：SoundEngine 新增 `startRoomTone(url)`：fetch → decodeAudioData → loop BufferSource → gain(0.5) → `inputNode`（compressor 前，SoundEngine.ts:416）。外部底噪在时合成床（startAmbient :72）增益减半作兜底；fetch/decode 失败自动回落纯合成，**不硬依赖外部文件**。入场 0s 淡入、34s 降到局内电平、章节过渡换层增益。

**格式要求**：OGG Vorbis（MP3 兜底同放一份）；44.1kHz；无缝 loop 20–60s；响度 ≈ -16 LUFS；单文件 ≤1.5MB；loop 点交叉淡化验证过；放 `public/audio/room-tone.ogg`。

**素材候选（许可已查）：**
1. **Sonniss GDC 合集**（主选）：免版税、免署名、免登录直下（gdc.sonniss.com，历年存档保留）。挑 basement/room-tone/drone 类 WAV，转码 OGG。许可边界：可嵌入成品游戏，禁止单独再分发、禁止 AI 训练——本项目用法合规。
2. freesound **kickhat「Ambient Drone 21.07.2018」** CC0：drone 兜底。
3. freesound **klankbeeld「basement tone 01 161005_1010」** CC-BY：最贴「地下室底噪」，但需署名+登录下载；仅当 Sonniss 选不出合适床时启用，并在 docs/CREDITS.md 署名。
4. freesound **toiletrolltube** CC0 低频 / **Atombata「Ego Loop 1」** CC0：纹理备选。

**合成新增**（不引外部）：打字机 tick、椅吱、锁舌、纸滑、缝线声（结局 B）、thump。全部走现有 tone/noiseHit helper 风格。
