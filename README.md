# Blood Ante · 血色底注

第一人称 3D 暗黑桌面博弈游戏。21 点博弈与霰弹枪裁决交替循环，穿过三层地牢的同一个讨债人。

**技术栈**：React 19 · TypeScript 7 · Three.js r187 · Tailwind CSS 4 · Web Audio 实时合成 + Mixkit/Pixabay 授权音效

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc -b + vite build → dist/
npm run preview    # 预览生产构建
```

## 玩法循环

1. **装弹与遗物**：弹仓（2–8 发，实弹/空膛混合并打乱）显示在 HUD 弹仓面板，双方从门前遗物中挑选道具。
2. **21 点博弈**：双方各发两张牌（你全明牌，对手 1 明 1 暗）。每回合最多使用 3 件道具（每次使用后有约 0.5 秒间隔），然后要牌或停牌。
3. **开枪**：胜者拿起霰弹枪，决定射向对手还是自己。实弹扣血，空膛只有金属撞针声。

- **爆牌** → 立刻判负；双方同时爆牌则本轮不开枪
- **黑杰克**（开枪时当前两张恰好 21 点） → 实弹伤害 +1
- **碾压**（赢下本轮且你的手牌 ≥20 点） → 实弹伤害再 +1
- **僵持** → 同点或双方爆牌时无人开枪，各摸 1 件道具，走火遗恨 +1（可叠加，真正扣血后清零）
- **弹仓** → 打空后才重装，不中途重洗

## 十三件道具

| 道具 | 效果 | 解锁 |
| --- | --- | --- |
| 放大镜 | 窥视下一发是实弹还是空膛 | 第 1 层 |
| 镇定剂 | 恢复 1 点生命 | 第 1 层 |
| 锯子 | 本局实弹伤害翻倍（2 → 4） | 第 1 层 |
| 磁铁 | 交换你的最后一张明牌与对手的明牌；互换后对手底牌亮出 | 第 2 层 |
| 手铐 | 跳过对手下一次行动 | 第 2 层 |
| 护心镜 | 下一次受到的实弹伤害完全挡下，随后碎裂 | 第 2 层 |
| 逆转沙漏 | 本局点数更小者获胜；单方爆牌仍判负，同点或双方爆牌仍僵持 | 第 3 层 · 玩家专属 |
| 献祭匕首 | 自损 1 血，双方手牌重发 + 弹仓重装 | 第 3 层 |
| 重锤 | 把膛内当前空膛砸成实弹（已是实弹则不可用） | 第 3 层 |
| 裁纸刀 | 自选一张手牌裁掉，不补牌（每回合一次，爆牌不可用） | 第 2 层 |
| 借据 | 你射向它的实弹 +2；它射来的实弹使你多受 1 点伤害（自射不触发） | 第 2 层 |
| 封条 | 亮出对手底牌，并自选封住其一张明牌（本回合不计点） | 第 3 层 |
| 单片眼镜 | 查看牌靴顶部三张，只有你知道，不改变牌序 | 第 3 层 |

## 三关 Boss

| 关 | 地点 | Boss | 它的生命 | 你的生命 | 遗物 | AI 性格 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 一层 · 验血厅 | 讨债人 | 6 | 7 | 2 件 | 保守：优先回血；≥15 点倾向停牌，但你停在 18 点以下时仍会跟到比你多一点；实弹率 >70% 才用锯子 |
| 2 | 二层 · 血账房 | 讨债人 | 8 | 7 | 3 件 | 激进：点数低于你明牌时 17 点也继续要，爱用手铐与磁铁 |
| 3 | 三层 · 补针刑台 | 讨债人 | 8 | 7 | 4 件 | 算牌：按剩余牌堆估爆牌概率，把停牌线在 19 点上下微调 1~3；下一发必实弹时献祭重洗 |

## 架构

```text
src/game/GameEngine.ts   纯逻辑状态机（不依赖 React / Three / DOM）
src/scene/               3D 场景 + 程序化贴图
src/audio/               Web Audio 合成音效
src/components/          画布桥接 + 规则图鉴
src/App.tsx              沉浸式 UI 覆盖层
```

跨层契约与协作规范见 **[AGENTS.md](./AGENTS.md)**。

## 美术资源替换

`public/assets/` 下放同名 PNG 即可覆盖程序化贴图（开发模式热替换）：`card-back.png`、`mask-1~3.png`、`table.png`。

## 部署

`base: './'`，构建产物可直接部署到任意静态托管（含子路径），不会资源 404。
